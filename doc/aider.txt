==============================================================================
*aider-introduction*

aider.nvim is a Neovim plugin that opens a terminal window inside Neovim and
runs Aider (https://github.com/paul-gauthier/aider), the AI pair programming
tool. Buffers are automatically added to and removed from the Aider context as
you open and close files.

You will need the aider CLI installed: https://github.com/paul-gauthier/aider

==============================================================================
*aider-setup*

The plugin exposes a `setup` function. Call it in your Neovim config:

  require('aider').setup(opts)

`opts` is a table with the following keys (all optional):

  auto_manage_context  boolean  Automatically add/remove buffers from the
                                Aider context as they are opened and closed.
                                Default: true

  default_bindings     boolean  Register the default <leader>A keybindings.
                                Default: true

  debug                boolean  Print debug messages to help troubleshoot.
                                Default: false

  ignore_buffers       table    List of Lua pattern strings. Buffers whose
                                name matches any pattern are excluded from the
                                Aider context.
                                Default: {'^term://', 'NeogitConsole',
                                         'NvimTree_', 'neo-tree filesystem'}

  border               table    Style the floating window border (only applies
                                when using the 'editor' window type).
                                Keys:
                                  style  string|table  Border style. Accepts
                                         any value accepted by nvim_open_win().
                                         E.g. "rounded" or a character table.
                                  color  string        Hex colour for the
                                         border highlight, e.g. "#fab387".
                                Default: nil (no border)

Minimal example (lazy.nvim): >

  {
    "dxas90/aider.nvim",
    opts = {
      auto_manage_context = true,
      default_bindings = true,
      debug = false,
    },
  }

Full example: >

  require('aider').setup({
    auto_manage_context = false,
    default_bindings = false,
    debug = true,
    ignore_buffers = { '^term://', 'NeogitConsole' },
    border = {
      style = { "╭", "─", "╮", "│", "╯", "─", "╰", "│" },
      color = "#fab387",
    },
  })

  -- Custom keybinding (only needed when default_bindings = false)
  vim.keymap.set('n', '<leader>Ao', ':AiderOpen<CR>', { noremap = true, silent = true })
<

==============================================================================
*aider-keybindings*

Default keybindings (set with which-key when available, plain keymap otherwise):

  <leader>Ao   Open Aider terminal window.
  <leader>Am   Add all git-modified files to the Aider chat.

  <leader><space>   Open Aider (DEPRECATED — will be removed in a future
                    version; use <leader>Ao instead).

Disable all default bindings by setting `default_bindings = false` in setup.

==============================================================================
*aider-commands*

:AiderOpen [args] [window_type]~

  Opens a terminal window running aider.

  args         Optional CLI flags to pass to aider (default: "").
  window_type  One of 'vsplit' (default), 'hsplit', or 'editor'.
               'editor' opens a floating window centred in the editor.

  If an Aider job is already running, AiderOpen re-attaches to it regardless
  of the arguments supplied.

  Examples: >
    :AiderOpen
    :AiderOpen -3 hsplit
    :AiderOpen --no-auto-commits editor
<

:AiderAddModifiedFiles~

  Adds all git-modified and untracked (unstaged) files to the Aider chat via
  /add. If Aider is not open it is started first.

==============================================================================
*aider-functions*

All functions live in the `aider` module.

require('aider').AiderOpen([args [, window_type]])~

  Programmatic version of |:AiderOpen|.

  Examples: >
    :lua require('aider').AiderOpen()
    :lua require('aider').AiderOpen("", "editor")
    :lua require('aider').AiderOpen("--no-auto-commits", "hsplit")
<

require('aider').AiderAddModifiedFiles()~

  Programmatic version of |:AiderAddModifiedFiles|.

NOTE: If an Aider job is already running, AiderOpen will re-attach to it even
if called with different flags.
